## 🚀 UNIVERSE TRAVEL SYSTEM

**Location:** Navigation Menu → Exploration Category → "Universe Travel System"

### What It Does
Calculate realistic interstellar travel between known locations in the Star Trek universe. Uses actual light-year distances, warp mechanics from The Next Generation era, and considers crew welfare.

### How to Use It

**Step 1: Select Your Starting Point**
- Click the "Origin Location" dropdown
- Choose from 10+ known Federation locations
- View origin details (sector, coordinates, description)

**Step 2: Choose Your Destination**
- Click the "Destination Location" dropdown
- Select any available location
- View destination details card

**Step 3: Set Your Warp Speed**
- Use the slider to select warp factor (1-10)
- Or click preset buttons (Warp 6, 7, 8, 9, 9.6, 9.9)
- See real-time calculations update

**Step 4: Calculate Route**
- Click "Calculate Route" button
- System displays comprehensive route analysis

### What Information You'll See

**Distance Display:**
- Light-Years (ly) - Standard astronomical unit
- Kilometers (km) - For precise calculations
- Parsecs (pc) - Alternative distance unit
- Star Sectors - Game-specific measurement

**Travel Time:**
- Formatted as Days, Hours, Minutes
- Includes warp stress assessment
- Shows if journey is safe at this speed

**Fuel Requirements:**
- Calculated fuel units needed
- Power output required
- Efficiency percentage
- Whether current supplies are adequate

**Route Safety Assessment:**
- Safety rating (Safe/Moderate/Hazardous)
- Anomaly detection results
- List of specific hazards:
  - Spatial anomalies
  - Stellar radiation
  - Meteor showers
  - Temporal distortions
  - Ion storms

**Crew Considerations:**
- Crew endurance evaluation
- Morale impact assessment
- Medical supply requirements
- Recommended rest stop locations
- Wellness warning for crew

### Tips & Tricks
- **Short Hops:** Use Warp 6-7 for efficiency
- **Emergency Travel:** Warp 9-9.9 increases fuel cost dramatically
- **Safe Routes:** Check hazard list before committing to travel
- **Crew Wellness:** Monitor morale impact for long journeys
- **Fuel Planning:** Verify fuel availability before departure

### Example Calculations
```
Earth to Vulcan at Warp 8:
- Distance: ~26 light-years
- Travel Time: 3 days, 12 hours
- Fuel Required: 3,200 units
- Route Safety: Safe
- Crew Impact: Moderate fatigue
```

## 🔬 TECHNOLOGY RESEARCH CENTER

**Location:** Navigation Menu → Science Category → "Technology Research Center"

### What It Does
Research and develop new technologies to improve your fleet's capabilities. Choose from 91+ technologies across 5 research tiers, gain access to powerful upgrades, and track your progress.

### How to Use It

**Step 1: Browse Available Technologies**
- View grid of all available technologies
- Color coding indicates rarity:
  - Gray = Common
  - Green = Uncommon
  - Blue = Rare
  - Purple = Epic
  - Orange = Legendary

**Step 2: Filter by Category or Tier**
- Use Category dropdown (10 options):
  - Engineering, Weapons, Shields, Propulsion, Sensors
  - Communications, Medical, Agricultural, Industrial, Scientific
- Use Tier dropdown (5 options):
  - T1 (Tier 1), T2, T3, T4, T5
- Combine filters for specific searches

**Step 3: Select a Technology**
- Click on any technology card in the grid
- View detailed information panel on the right

**Step 4: Review Technology Details**

**Technology Info Card Shows:**
- Tier (T1-T5 progression level)
- Rarity (Common to Legendary)
- Current Level / Max Level (1-10)
- Research Duration (in hours)

**Statistics Display:**
- Various attributes with progress bars
- Relative strength indicators
- Performance metrics

**Game Effects:**
- What this tech actually does
- Effect type (passive, active, aura, etc.)
- Which attributes it impacts
- Scaling behavior with upgrades

**Cost Breakdown:**
- Cost per level
- Scaling multiplier (increases with each level)
- Total cost to max out research
- Resource requirements

**Prerequisites:**
- Required technologies (marked with ✓ if completed)
- Shows which techs you need first
- Indicates locked techs you can't access yet

**Technology Synergies:**
- Related technologies that work better together
- Bonus effects from combinations
- Suggested tech combinations

**Step 5: Start Research**
- If prerequisites are met, click "Start Research"
- Technology added to research queue
- Progress bar shows current research status

### Understanding the Research Queue
- Only one technology researches at a time
- Queue shows next techs to research
- Progress bars show time remaining
- Estimated completion time displayed

### Tips & Tricks
- **Plan Ahead:** Check prerequisites before starting research
- **Synergies Matter:** Research complementary technologies together
- **Tier Progression:** Complete T1 before accessing T2
- **Build Paths:** Create themed builds (all weapons, all engineering, etc.)
- **Balance Research:** Mix different categories for versatile fleet

### Example Tech Trees
**Weapons Build:**
- Plasma Weaponry (T1)
- Phaser Array Enhancement (T2)
- Torpedo Acceleration (T2)
- Quantum Weaponry (T3)

**Engineering Build:**
- Warp Core Efficiency (T1)
- Power Distribution (T2)
- Quantum Reactors (T3)

**Science Build:**
- Sensor Array (T1)
- Subspace Analysis (T2)
- Temporal Mechanics (T3)

## 🎖️ PLANETARY COMBAT OPERATIONS

**Location:** Navigation Menu → Tactical Category → "Planetary Combat Operations"

### What It Does
Command ground forces in planetary assault missions. Deploy fleets to capture resources, gather intelligence, and defend your territory. Manage planetary defense systems.

### How to Use It

**Part 1: MISSION TRACKING (First Tab)**

**View Your Missions:**
- See all active planetary operations
- Each mission shows:
  - Mission Type (Raid, Attack, Spy, etc.)
  - Target Location
  - Assigned Fleet
  - Current Status (Active, Pending, Completed)
  - Progress percentage
  - Time Until Completion (ETA)

**Understanding Mission Types:**
1. **Raid** - Quick strikes for resources
   - Fast completion time
   - Moderate resource rewards
   - 40-60% success rate

2. **Attack** - Military assault
   - Destroy enemy forces
   - Combat damage rewards
   - 35-65% success rate

3. **Spy** - Gather intelligence
   - Non-combat intelligence operations
   - Information rewards
   - 50-75% success rate

4. **Sabotage** - Target destruction
   - Destroy specific facilities
   - Strategic advantage
   - 30-50% success rate

5. **Espionage** - Deep cover operations
   - Long-term intelligence gathering
   - Detailed enemy information
   - 45-70% success rate

6. **Siege** - Extended assaults
   - Lengthy operations
   - Maximum conquest potential
   - 25-45% success rate

**Mission Information Cards Display:**
- Success Rate percentage
- Expected Resource Outcomes:
  - Credits earned
  - Minerals obtained
  - Tech Points gained
  - Experience reward
- Time remaining and ETA

---

**Part 2: LAUNCH OPERATIONS (Second Tab)**

**Create New Missions:**
1. Select target location
2. Choose mission type
3. Assign fleet to mission
4. Set mission parameters
5. Click "Launch Mission" button

**Monitor Mission Progress:**
- Active missions show real-time progress
- ETA automatically updates
- Success rates calculated based on fleet strength vs. defenses

---

**Part 3: DEFENSE MANAGEMENT (Third Tab)**

**View Your Defense Systems:**

Each defense system shows:

**System Type & Name:**
- Cannon, Laser, Missile, Shield, or Detector
- Type determines capabilities

**Tactical Specifications:**
- **Range** (varies by type)
  - Cannon: 50km range
  - Laser: 35km range
  - Missile: 75km range
  - Shield: 100km radius
  - Detector: 150km range

- **Fire Rate** (how often it shoots)
  - Cannon: 5 shots/minute
  - Laser: 8 shots/minute
  - Missile: 2 shots/minute
  - etc.

**System Status:**
- **Level** (1-10 rating)
- **Strength** (damage output or effectiveness)
- **Durability** (health percentage with color indicator)
  - 🟢 Green (75-100%) = Operational
  - 🟡 Yellow (50-74%) = Damaged
  - 🔴 Red (0-49%) = Critical

**System Actions:**
- **Upgrade Button** - Increase level and strength (costs resources)
- **Repair Button** - Restore durability (costs resources)

**Defense Summary Dashboard:**
Shows overview of all defenses:
- **Total Defense Rating** - Combined strength of all systems
- **Operational Systems** - How many systems are fully functional
- **Overall Health %** - Average durability across all systems

### Defense Strategy Tips
- **Balanced Approach:** Upgrade all system types evenly
- **Counter Threats:** If under attack, upgrade relevant defense types
- **Maintenance First:** Repair damaged systems before upgrading
- **Cost Awareness:** Upgrades cost more at higher levels
- **Redundancy:** Have multiple systems of each type

### Example Defense Setup
```
High-Value Target (Strong Defense):
- 3 Cannon systems (Level 8-10)
- 2 Laser systems (Level 8-10)
- 2 Missile systems (Level 7-9)
- 1 Shield system (Level 10)
- 1 Detector system (Level 9)

Total Defense Rating: 85/100
Operational: 9/9 systems
Overall Health: 92%
```

## 📊 Resource Management

### What Are Resources?
Different systems use different resources:

**Universe Travel:**
- Fuel Units (required for travel)
- Time (hours for travel)
- Crew Endurance (morale/wellness)

**Technology Research:**
- Research Time (hours needed)
- Research Points (currency)
- Prerequisites (must complete first)

**Planetary Combat:**
- Fleet Units (for missions)
- Credits (from mission rewards)
- Defense Resources (for upgrades)

### Resource Planning
- Check costs before committing
- Plan long journeys with fuel in mind

- Upgrade defenses before they become critical

## 🆘 Troubleshooting

### "I can't see the new systems"
- **Check Menu:** Look in Exploration (Travel), Science (Research), Tactical (Combat)
- **Refresh Page:** Press Ctrl+F5 to hard refresh
- **Clear Cache:** Use Ctrl+Shift+Delete to clear browser cache

### "Calculations seem wrong"
- Verify your input values (locations, warp factor, etc.)
- Check that all values are within valid ranges
- Review the calculation steps displayed
- All calculations use documented formulas

### "A system isn't responding"
- Wait a moment (no system should lag)
- Check browser console (F12 → Console tab) for errors
- Reload page (F5) if system freezes
- Report any persistent issues

### "The menu won't open/close"
- Click the same menu item again to toggle
- Ensure you're clicking on the correct items
- Check if another menu is already open
