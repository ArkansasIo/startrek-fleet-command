## 🚀 Quick Start Guide

### 1. Import the System
```typescript
import {
  createFleetCombat,
  executeFleetCombat,
  generateFleetCombatReport,
  createStargate,
  createJumpGate,
  createHyperspaceRoute,
  // ... more functions
} from './GameSystems';
```

### 2. Create Infrastructure
```typescript
// Stargate network
const sg = createStargate('Gate Alpha', location, 5, ['sg_beta']);

// Jump gate
const jg = createJumpGate('JumpGate-1', location, 5000, 3);

// Hyperspace route
const route = createHyperspaceRoute('Route Zeta', start, end);
```

### 3. Initiate Fleet Combat
```typescript
const combat = createFleetCombat(
  'attacker_id',
  'defender_id',
  'fleet_id',
  'attack',
  'stargate',
  location,
  5000
);
```

### 4. Execute Combat
```typescript
const result = executeFleetCombat(
  combat,
  attackerFleet,
  defenderFleet,
  50
);
```

### 5. Generate Reports
```typescript
const report = generateFleetCombatReport(
  'incoming',
  'defender_id',
  'attacker_id',
  result,
  500,
  250
);
```
